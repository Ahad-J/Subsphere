## 2. Honest Feature Audit Matrix (Before v4.1)

| Capability Area | Current Status | Findings & Gaps |
|---|---|---|
| Auth, Tenancy, RBAC, Two-View Isolation | **implemented** | Registration, verification, login, JWT/cookies, `/api/v1/auth/me`, org creation, isolation verified in M0 & M7 tests. Live UI sign-in verified via `TestClient`; browser UI login recently fixed via `/api/v1/auth/me` alias. |
| Individual Subscription Add & List | **implemented (partial)** | `POST/GET/DELETE /api/v1/personal/subscriptions` works with currency separation. |
| Individual Subscription **Edit**, Tracking Status, & Reminder Reconciliation | **broken / absent** | Backend `PATCH` exists for a subset of fields (no `service_url`, `start_date`, `timezone`, `notes`, `tracking_status`, `version` conflict check, `quarterly`/`custom` intervals, and NO reminder job cancellation/rescheduling on renewal date edit). Frontend has NO Edit modal/drawer (`Add` + `Remove` only). |
| Month Grid Calendar (`Individual > Calendar`, `Provider > Calendar`) | **broken** | Frontend Calendar tab only renders flat date-bucket cards with `events` from `/api/v1/personal/calendar` for the current month only. No prev/next/today controls, no 7-column month grid, no mobile agenda toggle, no `/api/v1/calendar/events?from=...&to=...` projection across months, and no click-to-open details drawer. |
| SMTP Email Settings, Test Email & Background Reminder Scheduler | **broken (partial)** | `dispatcher.py` sends SMTP (`accepted_by_relay`) via manual trigger `/api/v1/notifications/dispatch`. Missing `GET/PATCH /api/v1/notifications/preferences`, `POST /api/v1/notifications/test-email`, `GET /api/v1/notifications/history`, `POST /api/v1/subscriptions/{id}/reminder-rules`, `GET /api/v1/integrations/email/status`, Settings UI, and background worker loop calling `schedule_personal_renewal_reminders` + `dispatch_email_jobs`. |
| Styled HTML/PDF History Report & Preview | **absent (partial)** | Invoice & payment receipts and a basic `statement` PDF exist, but Individual UI Reports tab only offers JSON export (`Export Personal History (JSON)`). Missing `GET /api/v1/history`, date/category/source filters, live HTML preview matching PDF dataset, styled multi-section PDF with spending chart & provenance notes, and `POST /api/v1/reports/{id}/send-email`. |
| Browser Extension MV3 Pairing, Background Tracking & History Import | **broken (partial)** | Basic `background.js` uses `tabs.onActivated`/`onUpdated` only and requires pasting raw user JWT in popup (`accessToken`). Missing pairing code flow, scoped revocable token (`tracking_connections`), `windows.onFocusChanged` / `idle.onStateChanged` focus guards, `options.html`, opt-in `chrome.history` local domain summary import, `activity_daily` dedupe table, and UI Connect Wizard. |
| Claude Code OpenTelemetry (`OTEL-01..04`) | **absent** | No OTel Collector Compose definition, no `ClaudeCodeOtelIngestAdapter`, no `/api/v1/integrations/otel/claude-code` or `/v1/metrics`, no cumulative/delta checkpointing (`otel_metric_checkpoints`), and no prompt/content strip gate on OTel events. |
| LiteLLM Gateway Wizard & Multi-Lane Routing (`LLM-01..05`) | **partial / unverified live** | Basic `/integrations/litellm/sync` stores usage records. Missing `/integrations/litellm/health` diagnostics, scoped virtual-key minting (`/integrations/litellm/virtual-key`), user-confirmed `/integrations/litellm/test-request`, API-key vs Claude-subscription lane instructions, and OTel-vs-LiteLLM request deduplication. |
| Provider Subscriber Edit, Overdue Reminder & Employee AI Usage | **partial** | `check-overdue`, `payments`, and `reports` work via API. Missing `PATCH /api/v1/subscribers/{id}` (edit UI + backend), per-invoice `POST /api/v1/invoices/{id}/send-reminder`, `GET /api/v1/provider/ai/usage` per-seat breakdown, and Provider 9-tab navigation/Calendar view. |
| Docker Compose Modularity & Scripts | **implemented (partial)** | Modular YAML files + `run-all.sh` exist; missing `compose.telemetry.yaml` (`telemetry` profile) and `Makefile` helper targets (`up-core`, `test-email`, etc.). |
